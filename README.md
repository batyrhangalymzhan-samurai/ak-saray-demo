# Ак-Сарай — 3D-сайт ресторана

Демонстрационный сайт ресторана и банкетного зала «Ак-Сарай» (Бесагаш).

## Запуск

```bash
npm install
npm run dev
```

Сборка для публикации:

```bash
npm run build
npm run preview
```

## Стек

React, Vite, Tailwind CSS, Three.js, React Three Fiber, Drei, Framer Motion, Lucide React.

## Структура

```
src/
  components/   секции сайта и 3D-сцена героя
  hooks/        определение reduced-motion, мобильного режима и WebGL
  data.js       все тексты и контакты (на русском)
  index.css     глобальные стили
```

## Важно

- Все изображения в галерее и на других секциях — иллюстративные стоковые фото (Unsplash). Они не являются фотографиями реального ресторана. Замените их на фото заведения перед публикацией.
- Меню, цены, вместимость банкетных залов и пакеты намеренно не указаны — уточните у владельца и добавьте в `src/data.js`.
- Сайт является неофициальным демонстрационным концептом.
